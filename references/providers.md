# 阶段 1/2：采购陪跑（RackNerd + Webshare）

原则：

- 价格/促销/页面文案会变——**现场打开官网核对**，本文数字只是写稿时的参考
- 所有点击与付款由用户完成；agent 开页面、指路、核对状态（见 browser-guide.md）
- 下单建议用**直连**（不挂代理）：信息更一致、少一层风控变量；两家官网在国内都可直接访问
- 账号信息：英文/拼音、真实可用邮箱、+86 手机、地址逻辑一致（省份-城市-邮编对得上）
- 任何凭证都不落盘、不回显、不写进消息里归档

---

## 1. RackNerd（买 VPS）

**推荐档位**：入门 1C1G（写稿时 $21.99/年；2G 档 $35.99/年——以官网为准）。

**机房**：能选美西（洛杉矶/圣何塞）就选美西；只有东岸也能用——身份链流量小，延迟不是关键（我们的实例在纽约州 Buffalo，~236ms，日常够用）。

**陪跑步骤（agent 开页 → 用户操作 → agent 核对）**：

1. agent 打开官网特价页，复述首页看到的套餐名和价格，请用户确认要哪档
2. 用户点「Order Now」进入配置页 → agent 核对：账单周期（年付）、机房下拉、系统（Ubuntu 24.04 或 Debian 12）
3. 用户填写账号信息（首次购买）→ agent 提醒：姓名拼音、邮箱一定真实（开通邮件发这里）、地址一致
4. 结算页 → agent 核对金额和期限 → **用户自己选支付方式并付款**：
   - 支付宝：最省事
   - USDT：选 TRC-20 网络，按**精确金额**支付，保存交易 txid
   - 信用卡：外币卡或加密卡都可试，被拒就换通道
5. 等待开通（通常几分钟）→ agent 核对：邮箱（含垃圾箱）是否收到含 IP + root 密码的开通邮件
6. agent 用一次性密码 SSH 登录 → **立即部署密钥并轮换密码**（见 server-setup.md）→ 用完的密码作废

**常见卡点**：

- 开通邮件进垃圾箱 / 延迟十几分钟——先等，别重复下单
- 支付宝通道偶尔维护——换个时间或换 USDT
- USDT 金额差一分都可能不到账——复制粘贴金额，别手输
- 下单后先别急着重装系统/换机房，先完成后续搭建（省得环境变来变去）

## 2. Webshare（买固定住宅 IP）

**推荐配置**：Static Residential → Private（1-2 人共享）+ Custom 1 IP + 250GB 带宽。写稿时 $1.5/月、年付 -30% ≈ $12.6/年——以官网为准；有条件的先月付试，确认可用再转年付（写稿时有 2 天退款窗口、用量 <1GB 可退——现场核对）。

**支付**：银联卡 / Apple Pay / 各类卡（写稿时不支持支付宝——现场核对）。

**陪跑步骤**：

1. agent 打开官网，带用户确认选的是 **Private 静态住宅**（不是免费的共享数据中心代理——那个不干净，别用）
2. 用户选 1 个 IP + 250GB 带宽，完成付款
3. 拿到凭证：代理地址、端口、用户名、密码 → agent 提醒用户**只填进客户端**，不要发到群里
4. agent 用一次性命令测试（凭证只出现在这一次命令里，不落盘）：
   `curl -x http://用户名:密码@地址:端口 https://api.ipify.org`
   返回住宅 IP 就算通
5. 记账：费用、续费日期、凭证存放位置（用户自己的密码管理器）记进进度文件

**使用纪律**（讲给用户听）：

- 250GB 是身份链专用：只给 AI 账号的网页/客户端流量用，不挂下载/流媒体/爬虫
- 一号一 IP：这个住宅 IP 不换用、不外借
- 如果以后要换 IP，先在客户端切好、验证通过再让账号接触新 IP

**推荐链接说明**：如发布者配置了推荐链接，用发布者的链接（例如 Webshare 的 `?referral_code=…`）——**不影响用户的价格**，可如实告知。
