# 阶段 0：问询与方案卡

固定项（不随用户变）：服务商推荐（VPS → RackNerd；住宅 IP → Webshare）与协议主线（Xray REALITY）。
不确定项（随用户变）：设备系统、手机、支付方式、预算、家宽运营商、已有设施——这些就是本阶段要摸清的。

规则：一次只问一题；给出选项和「不知道怎么查」的兜底解释；全部问完后输出一张方案卡给用户确认。所有价格数字标注「以官网为准」，不要报死价。

呈现方式：用 agent 的选项提问能力（opencode question / Claude Code AskUserQuestion / Codex 选项菜单），每题 2–5 个选项 + 1 个兜底项；没有选项能力的降级为文字编号（1/2/3）。多选类问题明确说「可多选」。

## 先探测，再提问

能自动查的绝不问用户。agent 先在本机跑一轮探测，把结果作为已知条件：

- 电脑系统/架构：`uname -a`（Linux/macOS）；Windows 用 PowerShell `[System.Environment]::OSVersion`
- 已装客户端：`which mihomo clash-verge`、看 `~/.config/clash-verge*` / `~/Library/Application Support/io.github.clash-verge*` 等路径
- 网络环境：`curl ip-api.com`（拿到运营商与出口 IP），顺带判断「能否直连海外」
- 浏览器：是否有 Chrome / 现有可连 CDP 的实例
- 手机：探测不了，必须问

探测结果先复述给用户确认（「我这边看到你用的是 X，对吗」），确认后再进入下面的问题。

## 问题清单（按顺序问）

1. 你的电脑是什么系统？
   - Windows 10/11 / macOS / Linux / 主要用手机
   - 兜底教查法：Win 按「设置 → 系统 → 关于」；Mac 点左上角苹果图标 →「关于本机」
2. 手机是什么系统？
   - 选项：苹果（iPhone）/ 安卓 / 不用手机 / 不知道怎么查（选了就教怎么看）
3. 你打算在哪里用这套出口？（可多选）
   - 电脑上的网页/客户端 / 手机 App / 都要
4. 你能用的支付方式有哪些？（多选，决定付款路线）
   - 支付宝 / 微信 / 银联卡（国内卡） / Apple Pay / 外币信用卡 / USDT 等加密货币
   - 如果一个都没有：先解决支付，再继续（这是硬门槛，别跳过）
5. 预算大概多少？
   - 入门（≤ ¥300/年）/ 进阶（¥300–1000）/ 不敏感，求省心
6. 已有条件盘点（避免重复买）
   - 已有 VPS？/ 已有代理订阅（机场）？/ 已有住宅代理？/ 已有能用的客户端？
7. 使用纪律确认（告知，不是商量）
   - 这套出口只给 AI 账号用：不跑下载/流媒体、不爬虫、不多账号、不共享给他人
8. 家宽环境
   - 大概哪家运营商（电信/联通/移动）？现在这台电脑能直接访问海外网站吗？
   - 用途：决定 VPS 线路建议，以及下单时「直连下单还是挂代理」的说明

## 决策矩阵

| 条件 | 推荐 |
|---|---|
| 有支付宝 | VPS 选 RackNerd（支持支付宝） |
| 有银联卡 / Apple Pay | 住宅 IP 选 Webshare |
| 有 USDT / 外币信用卡 | 两家都行；也可换其他 provider |
| Windows / macOS | 客户端 Clash Verge Rev（有图形界面，中文） |
| Linux | mihomo + 系统代理，或 Clash Verge Rev |
| iPhone | Stash（**付费 App ≈$3.99，需外区 Apple ID**，覆写 YAML 手贴）；免费替代：sing-box 官方 App / Karing；备选 Shadowrocket |
| Android | CMFA（官方、省资源）；纯小白或想和桌面端统一 UI → FlClash |
| 家宽移动 | VPS 优先东京，其次美西 |
| 家宽联通/电信 | VPS 东京或美西均可；预算足选 CN2/CMIN2 线路 |

## 方案卡（输出模板）

给用户一小段话 + 一张小表，包含：

- 要买什么：服务商、档位、价格（注明「以官网为准」）
- 用什么客户端：电脑 + 手机各一个
- 预计总耗时：哪几步需要本人操作（付款 ×2、手机配置 ×1）
- 这一步之后马上要做什么（一句话预告）

用户确认方案卡之后，才进入阶段 1。
